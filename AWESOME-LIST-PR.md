**PR Title:**

```
Add KERN MCP Security — static analysis scanner with autofixes
```

**PR Body:**

```
KERN MCP Security is a dev-time static analysis scanner purpose-built for MCP servers.

Unlike runtime monitoring or proxy-based tools, it catches vulnerabilities before code
ships — during editing (VS Code extension), in CI (GitHub Action), or on demand (CLI).

Key differentiators:
- 13 detection rules mapped directly to the OWASP MCP Top 10
- Autofix suggestions included for every finding
- Supports both TypeScript and Python MCP servers
- Works as a VS Code extension, CLI tool, and GitHub Action

Repo: https://github.com/KERNlang/kern-sight-mcp
```
